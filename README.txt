| Rock, Paper, Scissors - Javascript practice project |
    -----------------------------------------------
Each time the user makes a selection, a score will accumulate until the player or the computer reaches 5. The computer selection is randomized and compared to the user selection. The selections, results, and score are updated on the page and the browser console. When a score of 5 is reached, the winner is declared in the log. Upon the start of a new game, the score and the log is cleared.
